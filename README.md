# IPL Moneyball & Auction Strategy Analytics

## Project Overview

This project analyzes IPL player performance and auction prices to identify high-value players, underrated talent, and inefficient spending patterns.

Inspired by the Moneyball approach, the dashboard focuses on evaluating players based on performance relative to auction cost rather than reputation alone.

---

## Business Problem

IPL franchises invest hundreds of crores during auctions. However, expensive players do not always deliver the highest value.

This project aims to answer:

* Which players provide the best value for money?
* Which players are underrated or overrated?
* How does auction price relate to actual performance?
* Which players should teams target for a budget-efficient squad?

## Key Insights

* High auction price does not always translate to high performance.
* Several lower-priced players generated superior value scores.
* Performance-based evaluation can improve auction strategy.
* Data-driven decision making can help build stronger squads under budget constraints.
